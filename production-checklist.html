Complete these steps on Railway so the live site is secure and stable.

2. Railway Variables (required)

VariableExample / notes
ADMIN_PASSWORDLong password only you know
ADMIN_TOKENLong random string (e.g. 32+ characters)
DB_PATH/app/data/safarilink.db

Important: With NODE_ENV=production (or Railway’s environment), the app will not start unless ADMIN_PASSWORD and ADMIN_TOKEN are set. That is intentional for security.

What “production-ready” includes in this build

  • Required secrets in production (no weak defaults live)
  • Rate limits on login and public APIs
  • Security headers (Helmet)
  • Input validation and safer file names
  • Database indexes + graceful shutdown
  • Email on approve/reject when configured
  • Health check including database
